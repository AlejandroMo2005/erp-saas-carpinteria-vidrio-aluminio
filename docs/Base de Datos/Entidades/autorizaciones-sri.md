# Autorizaciones SRI

## Descripción

La tabla `autorizaciones_sri` almacena información relacionada con las autorizaciones de comprobantes electrónicos ante el Servicio de Rentas Internas (SRI).

## Estructura

La estructura de la entidad debe mantenerse conforme al esquema SQL de `inventario_proformas`, conservando los nombres, tipos, restricciones y valores por defecto definidos en la base de datos.

## Relaciones

La entidad se relaciona con los comprobantes electrónicos y con la información necesaria para registrar su proceso de autorización ante el SRI.

## Integridad

Las restricciones definidas en el esquema mantienen la integridad referencial de los registros de autorización.

## Referencia del esquema

Tabla definida como `autorizaciones_sri` en la base de datos `inventario_proformas`.
